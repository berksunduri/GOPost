| **Windows** | `GoPost.exe` — download and run |

> ⚠️ **macOS security warning?** The app isn't notarized yet (needs a $99/yr Apple Developer account).
> Here's how to open it — takes 10 seconds:
>
> 1. Open **Terminal** and run:
>    ```bash
>    xattr -dr com.apple.quarantine /Applications/GoPost.app
>    ```
> 2. Now open GoPost normally from Applications.
>
> *(This removes the quarantine flag that macOS adds to internet downloads.
> It's safe — you're explicitly telling macOS you trust this app.)*

> ⚠️ **Windows SmartScreen?** Click **More info** → **Run anyway**.
> Or right-click `GoPost.exe` → Properties → check **Unblock** → OK.

### 🗂️ Git-Native Workspace
GoPost is a file-backed HTTP workspace you can keep in git. Point the desktop app and CLI at the same folder — collections and environments are plain `.gopost.json` files under `collections/` and `environments/`.

Open a workspace from **Settings → Workspace** (or the empty-state **Open Workspace** action). The last folder is remembered; override anytime with `GOPOST_DATA_DIR`.

### 🏃 Shared CLI / CI Runner
`gopost run` no longer assumes only `~/.gopost` UUIDs. Pass `--data-dir`, run a collection by directory path, slug, or display name, and load envs with `--env` (`.gopost.json`) or `--env-file` for CI secrets.

```bash
gopost run --data-dir . --env ci --reporter junit --output results.xml checkout-api
```

Copy a ready-made command from Settings → Workspace. The GitHub Action takes `data_dir` and targets Go 1.25+.

### 📛 Reviewable Paths
New collections and environments use name-based slugs on disk (not opaque UUIDs). Existing UUID folders migrate to slugs when free. A workspace `.gitignore` template ignores `history/`, `runs/`, `settings/`, and logs.

### 🧪 Scripts & Auth in CI
Starlark pre-request and test scripts run in the CLI runner, same as the desktop app. API-key auth is applied on the wire for collection runs.

### 🔧 Also in this release
- Agent/contributor manual (`AGENTS.md`) and product design lock for the workspace model
- Packaging and README repositioned away from “Postman clone” toward git + CI
